# Fonts

Plus Jakarta Sans (variable, weights 200 to 800), used for all text of the app, the job page and the legal page.

- Files: `plus-jakarta-sans-latin.woff2` (Portuguese, Spanish, English and most Western languages) and `plus-jakarta-sans-latin-ext.woff2` (letters such as ł, ş, ő; the browser downloads it only when a text needs one of them).
- Source: the `@fontsource-variable/plus-jakarta-sans` package, version 5.3.0, files `plus-jakarta-sans-latin-wght-normal.woff2` and `plus-jakarta-sans-latin-ext-wght-normal.woff2`.
- Author: The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans).
- License: SIL Open Font License 1.1, in `OFL.txt` (free to use and redistribute, including commercially, as long as the license text goes with the font).
- Hosted here on purpose: no Google Fonts, so no visitor data goes to a third party.
- To update: replace both files with the same package's newer files and bump the `?v=` of `styles.css` in `index.html` and `apply.html`.
